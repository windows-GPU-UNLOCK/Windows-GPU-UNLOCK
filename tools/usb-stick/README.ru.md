# Флешка GPU-UNLOCK: полный гайд

[English](README.md) | **Русский**

*Vibecoded with love by Claude.*

`make-stick.ps1` превращает FAT32-флешку в загрузочную флешку GPU-UNLOCK **для вашего ПК**:
одна команда, два запуска. Скрипт проводит по штатному
[пайплайну локального профиля](../../docs/NEW-MACHINE.en.md) проекта и ставит перед анлоком
небольшое меню загрузки:

```
 GPU-UNLOCK boot menu
 Profile: LOCAL-220410de-145410de-dda39bf5

  1. Windows + GPU-Unlock
  2. GPU dump (read-only probe), then Windows without unlock
  3. Windows without GPU-Unlock

 Up/Down + Enter, or press 1, 2, 3.  Esc = 3.
 Item 1 starts in 20 s. Any key stops the timer.
```

Если флешка стоит первой в порядке загрузки BIOS, каждое включение проходит через это меню.
Пункт 3 или просто вынутая флешка загружают Windows как раньше. На внутренний диск ничего не
ставится, а анлок живёт в видеокарте только до выключения питания.

Чего скрипт не делает: не добавляет поддержку нового железа, не расширяет
`research/profile/proven.json` и не обходит проверки проекта. Проверки профиля, 22 теста,
привязка результатов тестов к исходникам и все проверки загрузчика и дочернего модуля работают как
есть. Если ваш ПК вне проверенного диапазона, скрипт остановится там же, где остановился бы проект.
Флешка с одного ПК на другом не сработает: проверки её отклонят, и Windows загрузится без анлока.

## 1. Подойдёт ли мой ПК

Нужно **всё** из списка:

- Одна видеокарта NVIDIA из [проверенного диапазона](../../docs/NEW-MACHINE.en.md#what-it-accepts):
  RTX 3090 / 3090 Ti, RTX 3080 12GB (`220a`), RTX 3070 8GB (`2484`), RTX 3060 Ti 8GB (`24c9`),
  RTX 3060 12GB (`2487` / `2504`). Точные чип, объём памяти и версия драйвера GOP проверяются
  потом по дампам. Производитель платы карты не важен. Других карт NVIDIA в системе быть не должно.
- Материнская плата с UEFI на прошивке **AMI** (большинство ASUS, MSI, Gigabyte, ASRock), CSM выключен.
- Мониторы подключены к RTX. Видеокарта должна быть единственным дисплеем прошивки, поэтому
  встроенная графика отключена или при загрузке ничего не выводит.
- Windows 10/11 x64, установленная в режиме UEFI.

Дампов ещё нет? `python -I .\tools\collect_compatibility.py` выведет безопасную опись железа
([START-HERE](../../docs/START-HERE.en.md)). Окончательный ответ дадут два дампа на шаге 4.

## 2. Подготовка Windows

1. **Скачайте репозиторий**: *Code → Download ZIP* и распакуйте в короткий путь, например
   `C:\GPU-UNLOCK\`, или сделайте `git clone`. Не запускайте ничего прямо из ZIP.
2. **Python 3.14 или новее** с [python.org](https://www.python.org/downloads/windows/) вместе с
   *py launcher*. Проверка: `py -3.14 --version`.
3. **Visual Studio 2022 Build Tools** (или Visual Studio 2022) с нагрузкой
   **«Разработка классических приложений на C++»** (MSVC v143 + Windows 11 SDK). Нужны для тестов на компьютере.
   LLVM 20.1.8 скрипт скачает сам (896 МиБ, хеш закреплён).
4. **Выключите быстрый запуск (Fast Startup)**, иначе «Завершение работы» не выключает ПК по-настоящему:
   *Панель управления → Электропитание → Действия кнопок питания → снять «Включить быстрый запуск»*,
   или в PowerShell от администратора:
   ```powershell
   reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Power" /v HiberbootEnabled /t REG_DWORD /d 0 /f
   ```
5. **BitLocker / шифрование устройства.** Посмотрите в *Параметры → Конфиденциальность и защита →
   Шифрование устройства* (или `manage-bde -status C:` от администратора). Если диск C: защищён, после
   выключения Secure Boot Windows спросит ключ восстановления. Найдите его заранее
   (https://aka.ms/myrecoverykey) или сначала выключите шифрование.
6. **Флешка в FAT32** (любой объём, проще всего 8–32 ГБ).
   - До 32 ГБ: *Проводник → правый клик → Форматировать → FAT32*.
   - Больше 32 ГБ Windows предложит только exFAT/NTFS. Используйте программу, которая умеет большой
     FAT32 (например Rufus: *Non bootable*, *Large FAT32*), или сделайте раздел ≤32 ГБ через `diskpart`.
     Проверьте, что выбрана именно флешка: форматирование всё на ней стирает.
   - Сам скрипт ничего не форматирует и не разбивает.
7. Около **2 ГБ свободного места** в `%LOCALAPPDATA%\GPU-UNLOCK` (LLVM, загрузки, сгенерированная прошивка).

## 3. Подготовка BIOS

Зайдите в BIOS (обычно **Del**; у ASRock **F2**) и выставьте:

| Настройка | Значение | Где обычно находится |
|---|---|---|
| Secure Boot | **Disabled** | MSI: Settings → Advanced → Windows OS Configuration → Secure Boot · ASUS: Boot → Secure Boot → OS Type = *Other OS* · Gigabyte: Boot → Secure Boot · ASRock: Security → Secure Boot |
| CSM / Legacy | **Disabled** (только UEFI) | раздел Boot (MSI: *Windows OS Configuration → BIOS UEFI/CSM Mode = UEFI*) |
| Основной дисплей | **PCIe / PEG**; встроенную графику выключить, если она выводит изображение | Intel: *Initiate Graphic Adapter = PEG*, *IGD Multi-Monitor = Disabled* · AMD: *Integrated Graphics = Disabled* |
| Порядок загрузки | флешка **первой** (когда она готова), Windows Boot Manager второй | Boot → Boot Option #1 |

Названия пунктов зависят от платы и версии BIOS, сверяйтесь с инструкцией к своей плате.

Разово выбрать флешку или Windows можно клавишей **меню загрузки**:

| Производитель | Меню загрузки | Вход в BIOS |
|---|---|---|
| MSI | F11 | Del |
| ASUS | F8 | Del / F2 |
| Gigabyte | F12 | Del |
| ASRock | F11 | F2 / Del |

Выбирайте пункт флешки, который начинается с **UEFI:**.

> Первая загрузка сразу после *Save & Exit* — это тёплый перезапуск, а не включение питания.
> Дамп в ней не снимайте: сначала ещё раз выключите ПК.

## 4. Сборка флешки

Откройте обычный (не от администратора) **Windows PowerShell** в корне репозитория. `E` в
примере — буква вашей флешки. Команда одна и та же для обоих запусков:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\usb-stick\make-stick.ps1 -Drive E -StageUnlock
```

Хотите сначала посмотреть, что будет? Добавьте `-Check`: так скрипт ничего не меняет.

**Запуск 1 (10–20 минут, в основном загрузки):**
- проверяет флешку, Python, Fast Startup, Secure Boot, BitLocker и MSVC;
- скачивает и распаковывает clang/lld-link 20.1.8;
- генерирует пять файлов прошивки NVIDIA прямо в Windows, без WSL;
- собирает пробу проекта (только чтение) и кладёт её на флешку за **меню фазы дампов**.
  В этом меню пункт 1 помечен как *not ready*, а на экране виден счётчик дампов на флешке.

**Потом два дампа:**
1. *Пуск → Завершение работы* (не «Перезагрузка»). Дождитесь, пока ПК полностью выключится.
2. Включите и загрузитесь с флешки (первая в порядке загрузки или через клавишу меню загрузки).
3. В меню нажмите **2**. Проба прочитает видеокарту (только чтение), сохранит на флешку
   `DIAGnn.TXT`, `PROM.BIN`, `IMGnn.BIN` и запустит Windows.
4. Повторите ещё раз. Нужно **2** дампа после **двух отдельных полных выключений**.

**Запуск 2 (та же команда, несколько минут):**
- проверяет дампы (`check-compatibility.py`). Если они расходятся, показывает, какой параметр или
  регистр PCI отличается, и что делать;
- запускает `research/profile/new-machine.ps1`: профиль → **22 теста** → USB-пакет → штатная запись проекта
  (загрузчик анлока, дочерний модуль, файлы прошивки);
- меняет меню фазы дампов на обычное. Флешка готова.

Без `-StageUnlock` второй запуск остановится после сборки пакета, и на флешку не попадёт ничего,
что пишет в видеокарту. Добавьте флаг, когда будете готовы.

## 5. Первый анлок и проверка

Первый раз будьте у компьютера.

1. Выключите ПК, включите, загрузитесь с флешки. Пусть сработает пункт 1 (или нажмите 1), дальше
   **ничего не нажимайте**.
2. Загрузчик проекта 5 секунд ждёт Esc (Esc там означает Windows без анлока) и проверяет, что карта
   в «холодном» состоянии. Затем экран ненадолго гаснет, выполняется одна защищённая операция,
   и сразу стартует Windows.
3. **Если экран чёрный дольше 2–3 минут:** выньте флешку, держите кнопку питания до выключения и
   включите снова. Windows загрузится как обычно; прошивка видеокарты никогда не перешивается.

Проверка результата:

- `RTX3090-UNLOCK\AUTO000000\REPORT.TXT` на флешке должен заканчиваться строкой
  `FINAL status=0 stage=transaction attempted=1 driver_release=0 clean=1`.
- Замер — [бенчмарком проекта](../../docs/BENCHMARK.en.md): `benchmark\setup.ps1`, `build.ps1`,
  `run-benchmark.ps1`, до (пункт 3) и после (пункт 1), на одном и том же драйвере.
  - Бенчмарк рассчитан на CUDA 12.6 и MSVC 14.29. В VS 2022 добавьте компонент *MSVC v142* и передайте
    обёртку `vcvars`, которая вызывает `vcvars64.bat -vcvars_ver=14.29`, либо соберите с
    `-AllowUnsupportedCompiler`.
  - Перед замером закройте всё, что грузит видеокарту: при загрузке выше 5% бенчмарк не стартует.
- На эталонной машине (RTX 3090, MSI Z390) FP16 вырос с 70 до 124 TFLOPS, BF16 с 70 до 129,
  TF32 с 36 до 65, FP32 не изменился. Игры и большинство программ не меняются: ускоряются только
  тензорные вычисления FP16/BF16/TF32 (обучение и инференс нейросетей).

## 6. Повседневное использование

- **Выключение → включение** даёт «холодную» карту, и пункт 1 её разблокирует.
- **Перезагрузка:** одни платы при перезагрузке сбрасывают карту (анлок применится снова), другие
  нет. Тогда загрузчик увидит «нехолодную» карту и просто загрузит Windows без анлока. Если анлок
  нужен, выключайте и включайте.
- **Сон и гибернация** сбрасывают анлок. Если он нужен постоянно, отключите сон.
- **Fast Startup должен оставаться выключенным.**
- Драйвер NVIDIA в Windows не участвует в загрузочной части. В отчётах встречались версии
  610.88–621.01. Если что-то ведёт себя странно, грузитесь через пункт 3.
- Не раздавайте флешку: в `RTX3090-UNLOCK\ASSETS\` лежит прошивка NVIDIA, только для личного использования.

## 7. Когда что-то меняется

| Что изменилось | Что делать |
|---|---|
| Обновление BIOS или настроек PCIe/графики, другая карта, другой слот PCIe, переустановка Windows (новый ESP) | `make-stick.ps1 -Drive E -StageUnlock -ArchiveCaptures`, затем два новых дампа (пункт 2), затем та же команда без `-ArchiveCaptures` |
| Новая версия репозитория | та же команда (она заново собирает, тестирует и записывает; если пожалуется на дампы, добавьте `-ArchiveCaptures` и снимите два новых) |
| Только меню (таймаут, пункт по умолчанию) | `make-stick.ps1 -Drive E -MenuOnly -MenuTimeout 10 -MenuDefault 3` |

## 8. Если что-то не так

| Что видно | Что это и что делать |
|---|---|
| Флешки нет в меню загрузки, или ПК её пропускает | Secure Boot ещё включён, CSM включён или флешка не FAT32. Выбирайте пункт **UEFI:**. |
| `Fast Startup must be off` | Шаг 2.4. |
| `Dumps are not usable yet: captures_disagree` | Скрипт покажет, что отличается. Регистры PCIe *Link Status* значат, что один дамп снят после тёплого перезапуска. Запустите с `-ArchiveCaptures` и снимите два новых дампа после полных выключений. Дампы никогда не правьте. |
| `cold_state` / *not in its power-on state* | Дамп снят после перезагрузки. В архив и переснять после полного выключения. |
| `outside_scope`, `gpu_scope`, `driver_scope`, `topology_scope` | ПК вне проверенного диапазона. На этом всё; можно отправить [отчёт о совместимости](../../docs/CONTRIBUTING.en.md). Не обходите проверки. |
| `attributes_mismatch` | Известный случай с кэшем атрибутов PCI ([#102](https://github.com/impacifist/Windows-GPU-UNLOCK/issues/102)); автоматический маршрут его не поддерживает. |
| В меню *the selected item returned* | Загрузчик или проба остановились до вмешательства в карту (например, не совпал хеш после пересборки: запустите `-MenuOnly`). Меню после этого загрузит Windows. |
| Чёрный экран после пункта 1 | См. п. 5.3. Потом пришлите `REPORT.TXT` и `HLS*.TXT` (без путей устройств) в issue. |
| Ошибка тестов во втором запуске | Не записывайте анлок. Сохраните вывод и откройте issue. |

## 9. Как всё откатить

1. В BIOS поставьте **Windows Boot Manager** первым (или выньте флешку) и снова включите **Secure Boot**.
2. По желанию включите обратно быстрый запуск.
3. Удалите `%LOCALAPPDATA%\GPU-UNLOCK` и папку репозитория, отформатируйте флешку.

Больше на ПК ничего не менялось.

## 10. Справка

### Параметры

| Параметр | Что делает |
|---|---|
| `-Drive E` | FAT32-флешка (обязательный) |
| `-StageUnlock` | во втором запуске записать анлок и обычное меню (иначе остановиться после пакета) |
| `-Check` | показать состояние и следующий шаг, ничего не записывать |
| `-MenuTimeout 1..99` | через сколько секунд стартует пункт по умолчанию (20) |
| `-MenuDefault 1/2/3` | пункт по умолчанию в обычном меню (1). В фазе дампов всегда 3. |
| `-MenuOnly` | пересобрать и записать только меню |
| `-ArchiveCaptures` | убрать старые дампы в `RTX3090-UNLOCK\old-*` (копия в `%LOCALAPPDATA%\GPU-UNLOCK\captures-archive`) |
| `-WorkDir`, `-Clang`, `-LldLink`, `-Python`, `-VcVars` | свои пути и инструменты |

Не перенаправляйте вывод (`*>&1`, `Tee-Object`) в Windows PowerShell 5.1. Тесты на Python пишут в
stderr, и такое перенаправление роняет скрипты проекта.

Устройство флешки, работа меню и генерация прошивки без WSL подробно описаны в
[английской версии](README.md#10-reference).

### Результаты

MSI MPG Z390 GAMING EDGE AC / i9-9900K / Inno3D RTX 3090 iChill X4 ([отчёт о совместимости #528](https://github.com/windows-GPU-UNLOCK/Windows-GPU-UNLOCK/issues/528)), все загрузки после полного выключения:

- два анлока через меню под присмотром (оба раза `FINAL status=0 clean=1`, Windows загрузилась);
- один дамп через пункт 2, совпавший со слепками профиля по всем сравниваемым значениям.

Бенчмарк проекта, до → после: FP16 70,0 → 124,2 / 123,4, BF16 69,9 → 129,0 / 128,9,
TF32 36,1 → 65,4 / 64,9 TFLOPS. Это одна машина, а не заявление о поддержке. Делитесь своими результатами ([CONTRIBUTING](../../docs/CONTRIBUTING.en.md)):
значения из `profile.json`, `REPORT.TXT` и замеры. `PROM.BIN`, `IMG*.BIN` и файлы прошивки не прикладывайте.
